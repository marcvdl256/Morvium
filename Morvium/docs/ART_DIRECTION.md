# Morvium Art Direction

## Visual direction

The final game uses a hand-drawn gritty 2D survival style rather than pure pixel art.

Core characteristics:
- dark post-apocalyptic atmosphere
- strong readable outlines
- muted earth tones
- brown, olive, charcoal and rust-red accents
- weathered wood, stone and metal
- readable silhouettes for gameplay

## Concept art rules

Concept sheets should use only functional labels:
- front / side / back
- animation/action names
- modular part names
- dimensions
- color palette
- technical/gameplay notes

Avoid decorative quotes, jokes and filler text.

## Game assets

The main character is intended to be built as a modular 2D rig with separated body parts.

Environment, zombies and modular tower pieces should follow the same visual language.
